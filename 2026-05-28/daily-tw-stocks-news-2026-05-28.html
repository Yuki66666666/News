03 📰 頭條大事 / Top Stories (5/27)
歷史里程碑 台灣市值

台灣股市躍升全球第五大；加權報酬指數首破10萬點
Taiwan Becomes World's 5th-Largest Stock Market; Total-Return Index Crosses 100,000 for First Time

來源: Bloomberg / Taipei Times · 2026-05-26~27 · Bloomberg連結
核心事實 / Facts

截至5月25日，台灣股市總市值攀升至4.95兆美元，超越印度（4.92兆美元），正式躍升為全球第五大股票市場，僅次於美、中、日、港。5/27，台股加權報酬指數（TAIEX Total Return）首度突破10萬點整數關卡，收100,966點，創下歷史新高。台積電今年累積漲幅達49%。

背景脈絡 / Context

台積電佔全球AI晶片晶圓代工份額超過90%，NVIDIA、AMD等AI大廠深度依賴台積電先進製程。COMPUTEX 2026（6月2~5日）黃仁勳、蘇姿丰等AI巨頭齊聚台北，帶動市場做多情緒。加權報酬指數反映含配息再投入的真實複利報酬，突破10萬點更具代表性意義。

影響觀察 / Implications

市值躍升吸引更多全球被動資金被動超配台股；MSCI新興市場指數中台股權重同步上修至23.76%，法人換股潮在5月29日生效前持續進行。散戶投資信心指數卻寫近三年低（38%當沖比），市場出現「散戶居高思危」與「外資加碼」分歧信號，值得持續觀察。

費半爆發 AI驅動

費半指數單日飆5.5%，引爆台股盤中最高大漲逾1,200點
Philadelphia Semiconductor Index +5.5% Ignites TAIEX's Intraday 1,200-Point Surge

來源: 聯合新聞網 / 鉅亨網 · 2026-05-27 · UDN連結
核心事實 / Facts

美股費城半導體指數（SOX）26日夜盤大漲5.5%，直接帶動台股27日開高走高，盤中最高飆1,292點至44,818點，多方一度欲強攻45K；終場收44,256.80，上漲731.43點（+1.68%），成交量爆出1.5568兆元近期天量，三大法人合計買超307.63億元，外資單邊大買381.28億元。

背景脈絡 / Context

費半爆發主因：美光（Micron）財報超預期（EPS大超估），且美光ADR在26日夜盤暴漲近20%市值首破兆美元，帶動整體記憶體、半導體設備類股全面激揚。台股記憶體族群華邦電（2344）創歷史新高，聯電（2303）漲停，IC載板欣興（3037）也首登千金股（盤中1,085元）。

影響觀察 / Implications

費半指數持續強勢將是台股下波攻勢的方向燈。聯發科漲幅達8.79%，市場解讀其受惠AI邊緣運算及手機AI需求同步爆發。半導體超強的背後是外資在現貨持續加碼（5/22已達史上第4大單日買超761億元），顯示外資對台股AI主題仍有高度信念。

影響觀察 / Implications
